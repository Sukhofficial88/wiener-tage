# Венские дни

Пилотная версия веб-приложения (PWA): пешая прогулка по Вене, в которой вы проживаете один день из жизни великого венца. Приложение следит за геопозицией, и у каждой точки маршрута само включает монолог героя. После первого открытия оно работает без интернета.

Сейчас в приложении четыре маршрута:

- **Моцарт**, 1 мая 1786: день премьеры «Свадьбы Фигаро».
- **Бетховен**, 6 октября 1802: Хайлигенштадт, день завещания.
- **Климт**, весна 1908: утро в Тиволи, день в мастерской.
- **Фрейд**, среда 1907 года: приёмная, Ринг и собрание по средам.

## Что умеет

- **Прогулка по GPS.** Кнопка «Начать прогулку» включает слежение за геопозицией. У каждой точки есть геозона радиусом 40–150 м; когда вы в неё входите, место отмечается пройденным, телефон вибрирует (на Android) и звучит голос героя. Нижняя панель показывает, куда идти дальше и сколько осталось, а кнопка «Как пройти» открывает Google Карты.
- **Демо-прогулка.** Проходит маршрут виртуально, чтобы опробовать приложение дома.
- **Голос.** Сейчас монологи читает синтезатор речи телефона. Приложение уже умеет играть записи: добавьте к остановке в `js/data.js` поле `audio: "audio/mozart/01.mp3"`, и вместо синтеза зазвучит запись.
- **Без интернета.** Service worker сохраняет приложение на телефоне; GPS интернет не нужен.
- **Установка на экран «Домой»** на iPhone и Android.
- **Уточнение координат.** В настройках есть режим для пилота: встаньте у нужной двери, нажмите «Записать мои координаты сюда», а потом скопируйте правки и перенесите их в `js/data.js`.

## Запуск на компьютере

Нужен только Python 3 (или любой другой статический сервер):

```bash
cd wiener-tage
python3 -m http.server 8080
```

Откройте http://localhost:8080. Геолокация и офлайн-режим работают только по `https://` или на `localhost`.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий, например `wiener-tage`.
2. Отправьте туда этот проект:
   ```bash
   git remote add origin https://github.com/<ваш-логин>/wiener-tage.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две приложение откроется по адресу `https://<ваш-логин>.github.io/wiener-tage/`.

Позже можно подключить собственный домен (например, `wienertage.at`) в том же разделе **Pages**.

## Установка на телефон

- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран Домой».
- **Android:** откройте адрес в Chrome → меню ⋮ → «Установить приложение».

Во время прогулки держите экран включённым: браузер на iPhone не следит за геопозицией с выключенным экраном. Приложение само просит телефон не гасить экран, если это поддерживается.

## Обновление

При любом изменении файлов увеличьте `VERSION` в `sw.js` (например, `wt-0.2.1`). Иначе установленные приложения продолжат показывать старую версию. После обновления приложение предложит перезагрузиться.

## Устройство проекта

| Файл | Что внутри |
| --- | --- |
| `index.html` | оболочка приложения |
| `css/app.css` | стили, светлая и тёмная темы |
| `js/data.js` | герои, маршруты, координаты, тексты |
| `js/app.js` | экраны, прогулка, геозоны, настройки |
| `js/geo.js` | GPS и демо-прогулка |
| `js/audio.js` | голос героя и «момент погружения» Бетховена |
| `js/map.js` | схема маршрута |
| `sw.js` | офлайн-режим |
| `manifest.webmanifest`, `icons/` | установка на телефон |
| `tools/make-icons.js` | генерация иконок (нужен Playwright) |

Сборка не нужна: это обычные HTML, CSS и JavaScript-модули.

## Точность координат

Точные координаты взяты из Wien Geschichte Wiki, Apple Maps и Wikipedia. Точки с пометкой `approx: true` поставлены по описанию улиц, и у них увеличенный радиус геозоны. Перед показом маршрута другим людям их стоит уточнить на месте в режиме уточнения координат.
